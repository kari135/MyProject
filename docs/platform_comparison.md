# Сравнительный анализ платформ для хранения репозиториев

## Сравнение GitHub и GitFlic

| Критерий | GitHub | GitFlic |
|----------|--------|---------|
| Страна | США | Россия |
| В реестре российского ПО | Нет | Да (№15861) |
| Бесплатные приватные репозитории | Да | Да |
| CI/CD | GitHub Actions | Есть |
| Интерфейс | Удобный, привычный | Менее привычный |
| Интеграции | Огромное количество | Ограничено |
| Документация | Обширная | Ограничена |
| Локальное развёртывание | Только Enterprise | Да |
| Санкционные риски | Есть | Нет |
| Экосистема | Огромная | Формируется |

## Преимущества GitHub
- Огромное сообщество и экосистема.
- Встроенный CI/CD (GitHub Actions).
- Множество интеграций.
- Подробная документация.

## Недостатки GitHub
- Санкционные риски для российских пользователей.
- Данные хранятся за рубежом.

## Преимущества GitFlic
- Включён в Единый реестр российского ПО.
- Возможность локального развёртывания.
- Соответствие требованиям безопасности РФ.

## Недостатки GitFlic
- Меньше функций и интеграций.
- Менее развитая документация.
- Меньше сообщество.
