# Обработка матрицы 
## Стратегия ветвления

В проекте используется **GitHub Flow**:

- `main` — стабильная ветка, всегда готова к релизу;
- `develop` — ветка для разработки новых функций;
- `feature/*` — ветки под отдельные задачи;
- после завершения работы — Pull Request и слияние в `main`.

**Обоснование:** простая модель, подходит для небольших команд и учебных проектов. Позволяет вести параллельную разработку без риска для стабильной версии.
