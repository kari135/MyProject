# Обработка матрицы

## Назначение
Программа расчёта элементов матрицы по формуле sin(j + 2) и подсчёта строки положительных элементов.

## Требования к окружению
- Операционная система: Windows
- Язык программирования: Python 3.x

## Инструкция по запуску

Для запуска программы выполните следующие шаги:

1. **Откройте терминал** (командную строку Windows или Git Bash).

2. **Перейдите в корневую директорию проекта** (если вы ещё не там):

   ```bash
